# RecallOps presentation script

Follow [the timed demo walkthrough](../DEMO.md). The prepared WebM records the actual deployed Vercel catalogue, sign-in screen, empty operator workspace, import interface, Settings and provider log. It contains captions and no audio. It makes no provider calls and shows no invented inventory outcomes. Exact chapter times are in the submission pack's `video/chapters.json`.

Suggested narration: “RecallOps helps electronics teams compare the individual units they own with official recall evidence. Search by model, brand or recall number, and open the original CPSC notice for current remedy instructions. Our public catalogue is a dated selection, not a complete recall feed. The owner workspace starts empty. Import genuine inventory, preserving unknowns instead of guessing. Anakin discovers and extracts official evidence; deterministic rules explain each unit's outcome. Affected units receive internal holds and tasks, while missing or conflicting facts remain review cases. Settings reports actual configuration and session state; provider history records actual calls. Monitoring starts paused and external delivery remains unverified.”

For an inventory demo, use your real records and either show the actual investigation wait or clearly identify previously completed results. Do not promise an affected outcome or represent controlled tests as real stock. Keep owner credentials off-screen.
